# 1.2.6 交付记录

## 界面与设置

新增独立「应用设置」页面，提供简体中文 / English、浅色 / 护眼 / 深色、减少动画、开机自启状态和版本检查。Claude 橘色继续用于主要操作和选中状态。「本机配置」调整到导航末尾，配置文件默认只展示已存在项，可切换未创建或全部；路径和修改范围分别展示。

设置开关改为统一组件：清晰的白色滑块、灰色关闭态和橘色开启态，保留禁用、悬停及键盘焦点。异步保存结束后恢复原控件的焦点；失败时保留上次已确认的值。减少动画同时覆盖开关过渡和页面动效。三种主题共用语义颜色变量，包含弹窗、选择器、检测状态和配置预览。

应用外观保存在独立的本机记录中，不随环境配置快照还原。桌面启动先读取外观，再创建窗口；原生菜单、托盘及页面标题随界面语言更新。界面翻译不改变系统语言、浏览器语言目标、配置、命令、原始证据或来源引文。

开机自启使用桌面系统接口，并读取系统确认结果。无法注册、需要系统批准和未确认写入分别提示，提供刷新和固定系统设置入口；浏览器、源码和隔离测试不会注册登录项。版本检查仅在点击后查询固定项目的公开正式 Release，区分有更新、无更新和未发布；查询失败可重试，不自动下载安装。

## 分层与健壮性

- 服务入口收敛为组装与启动，生命周期、操作互斥、HTTP 内核和各业务路由分别管理。
- 系统采样、网络采样与规则判断分开；持久化记录结构从业务服务抽出，减少反向依赖。
- 前端保留 `useGuard` 作为页面入口，按报告、扫描、配置、备份、项目与流程拆分内部状态和动作。
- 新增基于 TypeScript 语法树的分层检查，检查越层依赖和运行时循环，并纳入 `npm run check`。
- 长操作轮询拒绝旧请求结果和错误，重连时清理遗留运行状态；默认跟随最新报告，用户主动选择的历史报告保持不变。
- HTTP 接口区分正文过大、类型不支持与 JSON 无效；HEAD 不发送正文。单个浏览器资料读取失败不会使整个发现过程失败。
- 非首屏页面按需加载；首次检测前隐藏无结果统计。流程区分「未选择」与「未完成」，完成页优先显示剩余事项。

文献库现有 69 条来源。用户提供的原文章节对照仍为 43 项，环境检查仍为 31 项；不把界面设置扩充计作新增环境检查。

## 限制

- 登录项的真实系统批准、重启登录及 Windows / Linux 桌面交互未实机验证。macOS 包未签名、公证。
- 本轮 GUI 核对配置预览，没有执行最终全量快照还原；写入、冲突、回退及恢复依赖隔离自动测试验证。
- 翻译功能仍是模型配置和固定示例测试，尚未接入 Claude Code 原生会话。
- 外部 Chrome 的真实重启、定位系统服务和手机设置仍需在对应设备核对；不从 CG 内置窗口推断外部浏览器状态。
- 分层检查、测试通过不表示所有代码或所有系统场景没有问题。远程构建以本次提交的 GitHub Actions 为准。
