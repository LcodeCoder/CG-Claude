# 界面设计

产品是本机环境工作台，任务是发现问题、理解证据、审阅配置改动、恢复备份。

视觉基底：暖白 #f8f6f2、纸白 #fffdf9、炭灰 #2c2925；品牌使用 Claude 橘色 #d97757，交互按钮与文字使用更深的 #a94d30，兼顾阅读对比度。状态仍以文字与图标表达，并使用绿、琥珀和红色辅助识别。
字形：本地打包 Manrope 用于产品名与数字，中文使用系统苹方 / 微软雅黑，命令使用 JetBrains Mono。正文 15px，说明至少 13px，长说明行高 1.85；优先显示结论与下一步，证据按需展开。

新 Logo 是独立绘制的 C/G 开环组合，使用橘色底和纸白笔画，适合侧栏与小尺寸应用图标。SVG 是唯一源文件；`npm run icons` 生成 PNG、ICNS、ICO 与 favicon，避免各平台图标不一致。

布局：左侧 224px 导航，主区左对齐。顶部为环境身份与操作。主区由网络路径、检测汇总、可展开的检测行和修复侧栏组成。检查行按问题展开，命令与证据只在详情里出现。橘色表示用户操作，状态颜色表示检查结果。

             环境状态 / 最近检测

设计复核：避免用单一分数暗示账号安全；改为真实检测计数。避免把所有信息分成同规格卡片；主结果使用紧凑分组行，网络路径承担视觉辨识。没有检测的结果保留空状态，不展示伪造健康数据。移动端导航横向滚动，修复操作固定到结果末尾。尊重减少动效设置，支持键盘、可见焦点与对话框焦点管理。

## 1.1 交互补充

统计数字改为原生按钮，增加轻量箭头、悬停和选中反馈。点击清除旧搜索和分类，筛选对应状态；第一项自动展开、滚动定位并获得键盘焦点。只有一项需关注时直接展示该项证据，零结果显示明确空状态；无报告时入口禁用。按钮关联详情区域、可用 Enter/Space 操作，动态数量通过状态区域播报。减少动效偏好下立即定位。

配置向导为五步弹窗，确认页展示字段差异；执行页用纵向节点、连线、状态、尝试次数和可展开错误历史表达顺序。步骤切换滚回顶部，避免长预览影响流程首屏。不可编辑的节点明确提示仍将尝试，失败四次后跳过。

备份页将完整快照放在字段修复记录之前，突出「一键还原之前的配置快照」。还原弹窗先列出受影响文件与偏好，隐藏原文；按钮明确表示保存当前状态并还原。项目扫描页显示实际目录、固定读取范围与逐项证据，桌面版提供原生目录选择器。
