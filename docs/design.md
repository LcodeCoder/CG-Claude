# 界面设计

产品是本机环境工作台，任务是发现问题、理解证据、审阅配置改动、恢复备份。

视觉基底：暖白 #f8f6f2、纸白 #fffdf9、炭灰 #2c2925；品牌使用 Claude 橘色 #d97757，交互按钮与文字使用更深的 #a94d30，兼顾阅读对比度。状态仍以文字与图标表达，并使用绿、琥珀和红色辅助识别。
字形：本地打包 Manrope 用于产品名与数字，中文使用系统苹方 / 微软雅黑，命令使用 JetBrains Mono。正文 15px，说明至少 13px，长说明行高 1.85；优先显示结论与下一步，证据按需展开。

Logo 是原创交织星环：四个旋转交织环围绕中心八角星芒，结合用户希望的编织感与放射感，使用橘色底和纸白笔画。`public/logo.svg` 是唯一源文件，基础环只定义一次；`npm run icons` 生成 PNG、ICNS、ICO 与 favicon。各平台使用同一图形，版本参数和稳定资源的 no-cache 避免旧图标驻留。

布局：左侧 224px 导航，主区左对齐。顶部为环境身份与操作。主区由网络路径、检测汇总、可展开的检测行和修复侧栏组成。检查行按问题展开，命令与证据只在详情里出现。橘色表示用户操作，状态颜色表示检查结果。

草图：

    导航      环境检测                    本机连接    开始检测
             环境状态 / 最近检测
             浏览器 ─ 本机 ─ 解析 ─ 出口 ─ Claude
             通过 / 需处理 / 待确认
             检测分类与状态筛选       选中的修复
             可展开检测结果           预览修改

设计复核：避免用单一分数暗示账号安全；改为真实检测计数。避免把所有信息分成同规格卡片；主结果使用紧凑分组行，网络路径承担视觉辨识。没有检测的结果保留空状态，不展示伪造健康数据。移动端导航横向滚动，修复操作固定到结果末尾。尊重减少动效设置，支持键盘、可见焦点与对话框焦点管理。

## 1.1 交互补充

统计数字改为原生按钮，增加轻量箭头、悬停和选中反馈。点击清除旧搜索和分类，筛选对应状态；第一项自动展开、滚动定位并获得键盘焦点。只有一项需关注时直接展示该项证据，零结果显示明确空状态；无报告时入口禁用。按钮关联详情区域、可用 Enter/Space 操作，动态数量通过状态区域播报。减少动效偏好下立即定位。

配置向导为五步弹窗，确认页展示字段差异；执行页用纵向节点、连线、状态、尝试次数和可展开错误历史表达顺序。步骤切换滚回顶部，避免长预览影响流程首屏。不可编辑的节点明确提示仍将尝试，失败四次后跳过。

备份页将完整快照放在字段修复记录之前，突出「一键还原之前的配置快照」。还原弹窗先列出受影响文件与偏好，隐藏原文；按钮明确表示保存当前状态并还原。项目扫描页显示实际目录、固定读取范围与逐项证据，桌面版提供原生目录选择器。

键盘阅读可以从页面第一个按钮直接跳到当前标题，跳过侧栏导航；目标只移动焦点与滚动，不改写 URL。辅助导航与主导航统一标记当前页面，便于屏幕阅读器确认所在位置。

## 基础文字配色复核

2026-10-11 根据 `src/styles/tokens.css` 的实际色值计算代表性色对，并按 [W3C 普通文本最低对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 对照 4.5:1。以下数字保留两位小数，阈值比较使用未取整值。

| 用途                  |  对比度 |
| --------------------- | ------: |
| 正文 / 内容底色       | 14.25:1 |
| 辅助文字 / 工作区底色 |  5.55:1 |
| 橘色文字 / 内容底色   |  5.45:1 |
| 橘色文字 / 选中底色   |  4.61:1 |
| 通过状态 / 对应底色   |  5.86:1 |
| 关注状态 / 对应底色   |  5.51:1 |
| 错误状态 / 对应底色   |  5.59:1 |

本轮只覆盖上述基础色对，控件具体状态和叠加颜色仍按实际页面核对。默认桌面窗口、最小窗口、窄屏、摘要与完整阅读、键盘入口和向导按钮已经分别实测。后续改主题或覆盖样式时，应保留对比度、焦点和长文本换行的复核。

## 1.2.1 默认精简阅读

首页先显示检测计数和必要操作，删除重复页面简介、原文说明横幅、侧栏空间介绍与宣传文案。通过项只显示标题和状态，关注项保留一行原因；展开后仍可阅读检测范围、证据、下一步与来源。连接路径默认收起，原文对照从概览进入，43 项要求分为四组，筛选时自动展开匹配组。

文献默认显示标题、发布者、来源类型与核对日期，采用方式和关联检查按需展开；「详细」模式提供完整阅读。统计按钮仍清除旧搜索、筛选并定位第一项，证据与键盘交互保留。小窗口继续保证内容换行和弹窗按钮可达。

## 1.2.3 桌面常驻与状态提示

沿用现有阅读基线：底色 `#F8F6F2`、纸面 `#FFFDF9`、正文 `#2C2925`、次要信息 `#6A625A`、操作色 `#A94D30`、品牌标记 `#D97757`。中文正文优先系统中文字体，Manrope 用于拉丁文本。菜单栏图标从交织星环中移除色块，使用透明单色模板，以适配系统明暗外观；Windows/Linux 保留橘色。

窗口隐藏入口置于右上工具区，与配置操作分开。后台活动只显示一行进度，细节保留在原有检测列表和流程中。偏好编辑草稿在后台刷新时保留；已完成的保存不因刷新失败改称失败。没有新增宣传文案或密集说明卡片。

## 下拉框、帮助文案与翻译入口

各页面的 select 外观统一放在 `src/styles/forms.css`，页面样式只负责宽度和布局。闭合控件使用 44px 最小高度、纸白背景、可见焦点和统一内边距；支持 `appearance: base-select` 的浏览器使用同配色弹层、橘色选中项与受限高度。保留原生 select、option、标签和键盘选择；不支持的浏览器回退原生菜单，高对比度和减少动效偏好分别处理。

使用说明末尾的参考文献简介放在标题下方，和按钮共享卡片内边距。文案缩为「按来源分类，附核对日期、采用依据与适用范围。」；窄窗口下按钮换到下一行，避免文字贴边。

主导航增加「双向翻译」，单独展示中译英提交、英译中显示的流程与可切换示例。页面明确标为方案预览；示例只在组件内切换，不调用模型、不写入 Claude Code 会话。当前范围为提问和主回复，思考、工具调用、参数与结果保留原文。该页面和文献页一样，在本机服务离线时仍可阅读。
