# 1.2.5 交付记录

## 原文对照与配置流程

以用户提供的文章全文为基准，核对第 0–10 节和参考来源，归并为 43 项要求及执行边界。环境检测增加到 31 项，文献库增加到 67 条。全文仅在本机读取；仓库保留来源摘要哈希、采用段落与对应实现，不发布用户附件全文。

一键配置新增「按原文填入」，填入台北、TUN 和最少非必要流量的选项，仍需查看修改预览后执行。每个节点首次失败后最多重试 3 次，仍失败则跳过并继续。结束页默认收起执行记录，优先展示剩余事项：定位系统服务、手机时区、新终端复核、DNS、WebRTC、路由与账号核对。每项可展开步骤、设置入口、参考链接与命令；终端按钮仅打开空窗口，不执行复制的命令。

后续复检使用本次流程之后、检测偏好相同的最新报告更新清单，避免一直显示旧问题。旧人工勾选不能消除本次任务，新的人工确认也不能隐藏机器观察到的告警。按 IP 出口选择时区但尚无有效出口证据时，指引要求先复检，不退回台北。弹窗底部可以显示操作成功或失败的反馈，避免提示被原生对话框遮挡。

## 时区和快照

macOS 电脑自动设定时区、定位服务中的设定时区和手机设置分别检测或提示。自动时区读取失败保留待确认，不以当前时区推断开关；定位记录存在也不表示权限已经关闭。系统时区步骤在可读取的原系统时区基线确认后，可关闭已知开启的自动时区开关；管理员授权使用系统原生对话框。写入后独立回读，授权成功但读数延迟时只复核，不重复请求授权。

完整配置快照与还原预览包含已读取的自动时区开关。旧快照没有该字段时，不推断或修改开关。系统时区、Node/TZ 与浏览器采样仍分别取证，上海不能因与台北同为 UTC+8 而满足台北目标。定位页跳转通常只能到上层页面；系统服务「详细信息」仍由本人进入。

## 外部浏览器语言

「检测偏好」新增 Chrome、Edge、Brave、Chromium 的独立配置入口，可选择资料和固定英文目标，预览后保存，备份页可还原语言字段。写入前要求该浏览器完全退出，检查文件内容和权限，原子写入后回读；拒绝链接、异常类型和已观察到的组织强制语言配置。只备份语言字段，保留其他浏览器资料。

macOS 可另选应用语言，界面说明它会影响该浏览器的所有资料。网页首选语言只修改选中资料；旧资料缺少 `selected_languages` 时，同时保存和还原 `accept_languages`，避免重启迁移后无法恢复原语言。CG 内置窗口的语言检测不代表外部 Chrome。保存结果要求重新打开同一个浏览器复检，不直接宣称外部页面已经生效。

## 其他修复

- 桌面启动补足固定登录 shell 和常见安装目录的 PATH，优先使用已找到的绝对可执行路径。仅提取带标记 PATH，不导入其他环境变量或展示 shell 启动日志。
- IPv6 链路本地及 ULA 地址不再混作公网候选；只有本地地址也仅表示未观察到公网候选，不能证明没有泄漏。
- 修正 macOS ICNS 表示尺寸，各平台明确应用图标；保留托盘和 Dock 图标。
- 设置入口仅接受四个固定动作 ID，不接收任意 URL、路径或命令；演示模式不会打开真实系统设置或终端。
