## 时区规则修正（2026-10-11）

重新完整读取 AYi 原文。第 2.2、6.1、9 节明确建议台北，并要求关闭自动设定时区、关闭定位服务里的设定时区、核对手机端。之前把未填写期望时区视为通过，且只核对浏览器和 Node 进程是否一致，漏掉了原文的目标和独立系统证据；该判定已修正。

规则 `2026-10-11.9` 默认采用原文 `Asia/Taipei`。用户也可明确选择按当前 IP 出口返回的有效 IANA 时区检测，或手动选择；结果逐项标明依据、当前值、目标值和原文基准。按出口模式不按国家或 UTC 偏移猜时区，未开启公网检测、查询缺失或两侧出口不同均待确认。这里比较的是本次本机出口观测，不证明 Claude Code 的实际请求路由。

系统时区从 `/etc/localtime` 或只读系统命令获取，Node 进程的 `Intl` 时区另行保留；`TZ` 不能替代系统证据。Windows 已映射常用区域 ID，未映射 ID 保留原读数并待确认。自动时区、定位服务和手机端作为独立待确认检查。设置页和配置向导共用选择组件；保存偏好只保存检测目标，不修改系统时区。旧报告保留原结果和规则版本，页面明确提示重新检测。

完整设计和验证边界见 [时区检测说明](timezone-detection.md)。
