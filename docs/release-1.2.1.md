# CG Claude 1.2.1 交付记录

生成日期：2026-10-11（Asia/Shanghai）。本轮同时修正原文对照和检测边界，并按用户反馈精简默认界面、更新品牌图标。

## 主要变化

- 默认界面只呈现结论和必要操作：通过项只显示标题、状态；关注项保留一行原因，证据与下一步展开查看。连接路径、原文对照和文献采用方式默认收起。
- 删除重复介绍与宣传文案，侧栏保留功能入口；文献提供「精简 / 详细」两种阅读方式，统计卡片仍可筛选、展开并定位具体结果。
- 原创「交织星环」Logo：四个交织环与中心八角星芒，橘色底、纸白笔画。单一 SVG 源同步生成桌面图标和 favicon；稳定静态资源使用 no-cache，避免旧图标驻留。
- 28 项环境检查，规则版本 `2026-10-11.11`。系统时区独立取证，以原文的 `Asia/Taipei` 为默认目标；也支持有效 IP 出口时区或手动目标。上海与台北不会因同为 UTC+8 而判为一致，设置页只改变检测目标。
- WebRTC 与公网出口需要有效浏览器证据；npm/Git 查询失败、出口未查明、Git include 与无法确定的 TLS 声明均保留待确认。Git TLS 检查覆盖 URL 子节与旧式 dotted 子节，不自动修复 Git TLS。
- [原文审计](article-audit.md)整理 43 项要求与边界：3 项自动、14 项部分自动、22 项人工、4 项不自动执行。[来源审计](reference-audit.md)逐条标明 46 条来源的采用段落、实现位置与限制。人工复核共 19 项。
