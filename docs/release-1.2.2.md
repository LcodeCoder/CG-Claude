# CG Claude 1.2.2 交付记录

生成日期：2026-10-11（Asia/Shanghai）。成品代码对应提交 `28d1078`，后续验证文档不改变安装包。本轮补齐一键配置中的系统时区、终端与 Claude Code TZ 写入，并接入操作系统授权和时区快照还原。

## 主要变化

- 一键配置增加「设置系统时区」与「配置终端与 Claude Code TZ」两个独立节点，默认勾选，可分别取消；流程共 13 个节点，首次失败后最多重试 3 次，再失败就跳过并继续。
- 原文模式使用 `Asia/Taipei`，也可选手动目标或当前 IP 出口。预览冻结具体目标，出口缺少有效时区或两侧出口不同会阻止配置，执行前检查文件和时区是否改变。
- 系统时区修改使用原生授权：macOS 管理员密码窗口、Windows UAC、Linux polkit。应用不接收或保存密码；写入后独立读取系统时区核对，命令返回成功不能替代实际读数。
- 终端 TZ 写入白名单启动文件和 Claude `env.TZ`；Windows 另保存用户 TZ。同步本工具进程，已有终端和 Claude Code 会话需要重新打开。不新增会改变 Bash 登录优先级的 `.bash_profile` 或 `.bash_login`。
- 完整快照记录 11 个用户配置位置、检测偏好及可读取的系统时区、进程 TZ 和 Windows 用户 TZ。还原前另存当前状态，预览展示时区差异；旧快照保持原来只含文件与偏好的范围。
- 配置完成后通过一次性采样请求读取新的浏览器时区，再连续检查 3 遍。旧样本不复用，采样超时保留未检测，重放请求被拒绝。
- 规则版本为 `2026-10-11.12`。仍为 28 项环境检查、19 项人工复核、43 项原文对照；增加 7 条官方实现依据，文献共 53 条。

自动时区、定位服务、手机端与账号状态仍需人工复核。系统授时/NTP 设置保持原值，系统时区配置不代替这些检查。
