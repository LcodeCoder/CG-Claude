# 1.2.4 交付记录

## 本次变化

左侧「双向翻译」首屏新增真实模型配置：接口协议、API 地址、模型名称、密钥与测试超时。可保存到本机，使用两段固定示例测试中译英和英译中。支持 OpenAI 兼容 Chat Completions 与 Anthropic Messages。Claude Code 原生终端尚未接入，保存或测试不会安装 Hooks、翻译真实会话或改变工具内容。

密钥使用 AES-256-GCM 加密，主密钥单独保存在私有记录目录；这是本机文件加密，拥有该目录读取权限的人仍可解密。界面不读取已存密钥，修改协议或实际接口地址后需重新填写密钥。测试禁止重定向，对直连、代理隧道内的目标服务及 HTTPS 代理分别保持证书校验，使用本机代理设置和有限超时，最多读取 128 KB 响应，不自动重试可能收费的请求。

环境检测增加「浏览器首选语言」，检查数为 29。分别核对语言、地区标记与首选列表：例如 en-CN 和 en-US 都是英文，地区不同仍不能通过 en-US 目标。检测偏好和配置向导提供目标选择及四种浏览器的官方设置指引；详情可跳转到设置。仅采集当前 CG 窗口，外部登录浏览器需单独核对。一键时区配置不修改外部浏览器语言。该项是用户需求的独立扩展，原文没有要求必须改成英文。

修复系统时区写入延迟导致的「已跳过」误报。命令获确认后等待独立系统读数，后续重试只复核；本流程尝试的目标已生效且其他时区层未变时，接受延迟读数。真实读数没有改变仍不能判成功。原始配置快照与历史流程结果保持各自记录时的内容。

本机隔离界面验证模型保存、刷新后读取、密钥占位与复用、鉴权错误提示、协议切换保护、两种接口的双向测试、折叠示例和语言设置跳转。连续三遍检测均完成，29 项结果各轮一致。有效 375 px 窄窗口没有水平溢出。macOS arm64 新 Electron 成品已启动，实际保存模型设置并完成双向测试，证明打包后的运行依赖可用。最终成品再次完整加载界面，读取已存配置，并通过应用正常退出，退出码为 0。测试服务只在本机模拟，不使用用户真实密钥，不调用远程收费模型。

参考文献及采用段落审计增加到 64 条。Mozilla 直接获取返回 Client Challenge，已更正来源记录，采用段落通过网页读取渠道核对；挑战页面未计作文章正文。

收尾只读复核：11 个用户配置位置的内容哈希、权限和读取状态与当前基线一致。系统时区在先前 America/Los_Angeles 基线之后变为 Asia/Shanghai，自动设定时区开关读到启用；本轮没有提交真实系统时区写入。变化原因未作断言，也未覆盖当前设置。系统当前正确与否以重新检测为准，自动时区仍需人工复核。
