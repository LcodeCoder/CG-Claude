# 1.2.3 交付记录

日期：2026-10-11。平台：macOS arm64。

## 本次变化

- 桌面支持菜单栏／系统托盘常驻。最小化和关闭窗口保留后台任务；图标菜单提供打开、隐藏、进度和退出。托盘不可用时保留普通窗口行为。
- 本机记录增加结构与完整性校验。损坏的记录保留原文件并停止操作；旧备份在恢复前核对原始内容；快照恢复保护其他程序修改的权限、偏好和时区。
- 页面重连接回正在运行的检测和配置任务。写入请求为系统授权留出时间，明确区分操作成功、结果未知和界面刷新失败；确认写入后旧报告立即停止提供修复入口。
- 旧偏好的字段顺序变化不再被当成设置改变；界面后台刷新保留未保存的草稿。浏览器打开桌面服务时不显示无法使用的原生按钮。
- 项目锁文件是目录或符号链接时改为待确认，说明不可读取的原因。

## 已验证

23 个测试文件通过：340 项通过、1 项仅 Windows 的测试在 macOS 跳过。类型检查与生产构建通过。回归覆盖记录损坏、旧记录兼容、完整性校验、权限冲突、客户端断开后的退出等待、请求异常、授权等待、重连、旧偏好字段顺序和托盘资源清理。

macOS 开发窗口已执行最小化和应用内隐藏操作，并通过「窗口 → 打开主窗口」恢复。隔离浏览器页面实际执行三遍检测并重载读取结果；修复选择保持可用，旧偏好不再出现虚假的变化提示，原生隐藏按钮不出现在浏览器中。系统菜单栏图标点击入口与 Windows/Linux 托盘未完成实机交互验证，相关生命周期由注入原生适配器的测试覆盖。

真实本机只执行读取。11 个配置位置与 10:54 的当前基线一致，系统仍为 Asia/Shanghai，15721 网关保留。本轮命令行三遍检测未提交浏览器样本且未开启公网查询，结果为 15 通过、3 关注、6 待确认、4 未检测，各轮一致。现有的偏好、21 份报告、8 份快照、3 份配置流程、3 份备份与 2 份人工记录均能通过新版读取验证。
